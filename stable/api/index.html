API

NonconvexUno.UnoAlg — Type
UnoAlg()

Uno nonlinear optimizer, accessed through UnoSolver.jl. Supports continuous variables, finite/infinite bounds, and nonlinear equality/inequality constraints. Configure the algorithm with UnoOptions.

NonconvexUno.UnoOptions — Type
UnoOptions(; first_order=true, linear_constraints=false,
             preset="ipopt", hessian_model=nothing, kwargs...)

first_order=true (the default) maps to hessian_model="LBFGS": a first-order, limited-memory quasi-Newton method. first_order=false maps to hessian_model="exact". An explicit hessian_model ("exact", "LBFGS", "LSR1", "identity", or "zero") overrides first_order.

linear_constraints=true caches the constraint Jacobian. Remaining keywords are Uno options (for example max_iterations, primal_tolerance, dual_tolerance, and logger="SILENT"). Other presets include "filtersqp", "funnelsqp", and "filterslp".

Inconsistent combinations are rejected: Uno's L-SR1 Hessian model is not supported with the interior-point method (the "ipopt" or "auto" preset, or an explicit inequality_handling_method="interior_point"); use an SQP preset such as preset="filtersqp" with LSR1 instead. Unknown option names are also rejected here, in Julia, against the option table of the pinned Uno binary (Uno 2.9.3 via UnoSolver.jl 0.3.10), before any C call.

Derivatives use NonconvexCore's AD backend and dense, fixed coordinate patterns.

NonconvexUno.UnoWorkspace — Type
Workspace(model::NonconvexCore.VecModel, UnoAlg(), x0; options=UnoOptions(),
          lagrangian_hessian=nothing)

Construct a reusable UnoWorkspace. Convert other Nonconvex models with NonconvexCore.tovecmodel first. NonconvexCore.optimize!(workspace) solves from workspace.x0; NonconvexCore.reset!(workspace, x0) replaces that initial point. Iteration callbacks are currently unsupported. A custom lagrangian_hessian receives (x, objective_multiplier, constraint_multipliers) and returns a matrix.

NonconvexUno.UnoResult — Type
UnoResult

Result of a Uno solve. Fields: minimizer, minimum, native problem, full Uno execution statistics in result, symbolic status, and objective evaluation count fcalls. On convergence status == :first_order; this denotes the optimality condition, regardless of the Hessian mode used.
